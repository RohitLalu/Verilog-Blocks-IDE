Download VerilogBlocks IDE

The latest version for your system. Yosys, Icarus Verilog and SymbiYosys come with the app, and cocotb and pyuvm on macOS and Linux; nothing else is needed to draw, simulate, synthesise and time a design.

macOS
Apple silicon (M1 or newer)
Download .dmg or the .zip
First launch

Open the .dmg and drag the app to Applications. The app isn't signed by Apple yet, so macOS may say it is "damaged". Run this once in Terminal, then open the app normally:

xattr -dr com.apple.quarantine "/Applications/VerilogBlocks IDE.app"

Windows
Windows 10 or 11, 64-bit
Download installer or the portable .zip (no installation)
First launch

The installer isn't code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Click More info, then Run anyway. It installs for your user only; no admin rights needed.

Linux
64-bit x86
Download AppImage
First launch

Make the file executable, then run it:

chmod +x VerilogBlocks-IDE-linux-x86_64.AppImage
./VerilogBlocks-IDE-linux-x86_64.AppImage

System requirements

SystemNeeds
macOSA Mac with Apple silicon (M1 or newer). Intel Macs are not supported.
WindowsWindows 10 or 11, 64-bit (x64). ARM-based Windows PCs are not supported yet.
Linux64-bit x86 with a desktop; built and tested on Ubuntu 22.04, so a distribution of that age or newer.
AllAbout 1 GB of free disk space. The optional learning assistant needs about 1 GB more for its model and runs comfortably with 8 GB of RAM.

The app's ⚙ Tools window shows exactly which tools it found, their versions and locations.

Check a download, or get an older version

Every version, with its release notes and the SHA-256 checksum of each file, is on the GitHub Releases page. To check a file:

# macOS / Linux
shasum -a 256 VerilogBlocks-IDE-mac-arm64.dmg
# Windows (PowerShell)
Get-FileHash VerilogBlocks-IDE-Setup-x64.exe -Algorithm SHA256

Docker or from source

For labs and servers, the same app runs in a browser from a Docker container (it builds atalanta for itself). Or build the desktop app yourself; you need Node.js 20 or newer.

git clone https://github.com/RohitLalu/Verilog-Blocks-IDE.git
cd Verilog-Blocks-IDE/verilog-ide

docker compose up -d        # browser version at http://localhost:3000

npm ci && npm run start     # or: the desktop app in development mode
                            # (development uses Yosys and Icarus Verilog from your PATH)

Details in the README.
